Every terrain tile in the game, painted live by buildTileAtlas() in src/sprites.js each time this page loads. Edit a tile's paint code and it changes here on refresh — this is the same canvas the world renderer draws from.

The atlas as the game builds it

One canvas, — four variant columns across, one row per tile type. The renderer picks a column with hash2(tx, ty, 7) so terrain never visibly repeats, except for water and tide flats, where the column doubles as an animation frame.

Replacing these with your own art

Everything downstream — the world renderer, minimap, interiors, collision — reads tiles only through this atlas, and reads them by (column, row). So a texture pack never has to touch worldgen: paint into the same grid and the rest of the game cannot tell the difference.

    Sizes, flags and habitat mappings on this page are read from the live code (CELL, T, isSolidTile(), isWaterTile(), habitatTypes()), never transcribed.
